SoLoud
======

[SoLoud](https://github.com/jarikomppa/soloud) is an easy to use, free, portable c/c++ audio engine for games.

This is a fork that adds the following changes:
- SDL3 backend based on the reworked [PR #402](https://github.com/jarikomppa/soloud/pull/402)
- DirectSound backend
- New build process using CMake 3
- Numerous minor fixes across the codebase.

![ScreenShot](https://raw.github.com/jarikomppa/soloud/master/soloud.png)

Zlib/LibPng licensed. Portable. Easy.

Official site with documentation can be found at:
 http://soloud-audio.com
